# Міграція профілів між Supabase і VPS

Обидва модулі встановлюються вимкненими. Цей проєкт містить **лише** функцію й міграцію джерела. Його не слід застосовувати до цільової PostgreSQL або до іншого Supabase-проєкту.

1. В ізольованому клоні джерела звірити фактичні схеми `auth.sessions` і `public.svitlo_profiles` та всі способи запису адрес, назв і налаштувань. Перевірити стару PWA і старий APK на читання й звичайний запис із вимкненим модулем.
2. Налаштувати через сховище секретів проєкту `SVITLO_MIGRATION_BRIDGE_KEY`, `SVITLO_MIGRATION_SOURCE_SIGNING_KEY` (окрема Ed25519 пара) і `SVITLO_MIGRATION_TARGET_PUBLIC_KEY`. Цільовий API монтує `/run/migration/config.json`: `url`, `publishableKey`, `bridgeKey`, `targetOrigin`, `privateKey`, `publicKey`, `sourcePublicKey`. Встановити дозволи читання тільки процесу API. Не повторно використовувати пару підписів джерела на цілі.
3. Спочатку встановити функцію та перевірити підпис на ізольованому джерелі. Перевірити свіжий `getUser`, активну сесію, захист від іншого subject, тайм-аут і повтор, запис лише одного боку та підписане скасування. Перевірити, що незнайомі джерельні адреси не імпортуються частково й датчики не переходять новому власнику.
4. Лише після цих доказів увімкнути прапорець джерела й цільовий cohort для одного добровільного тестового акаунта. Звірити власника й копію в попередньому перегляді. Після commit повторити з тими ж двома сесіями: ціль має повернути ту саму квитанцію, а джерело залишитися заблокованим на запис.
5. Зупинити розширення cohort при помилці. Підтверджений commit ніколи не відкочувати розблокуванням старого writer. Для завислої незавершеної операції повтор з тим самим підписаним envelope або після його строку ініціює перевірку квитанції та доставку підписаного скасування. Не змінювати fences вручну; спочатку перевірити durable receipt на цілі.

Документація: [Supabase getUser](https://supabase.com/docs/reference/javascript/auth-getuser), [секрети Edge Functions](https://supabase.com/docs/guides/functions/secrets), [пряме підключення PostgreSQL](https://supabase.com/docs/guides/functions/connect-to-postgres).
