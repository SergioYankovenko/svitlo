# MAP-01 / BE-09 · Visicom fallback

Private VPS/PWA implementation, 3 November 2026. Provider catalog remains the first lookup. The fallback is currently enabled for supported available Cherkasy operator city routes; it is not a claim of Ukraine-wide coverage.

`POST /api/v1/map-search` accepts `{schemaVersion:1,cityId,street,house,streetId?}` with the existing reader cookie, Origin and CSRF. Existing exact provider address returns `provider_found` without calling Visicom. A provider/database failure is an error. A successful missing lookup may return `found` with explicit candidates, or `not_found`; neither result certifies legal address existence.

api-anything is pinned to upstream commit18772b45e8c99ce8e45067500f7e69a788ede14e in the local MIT tarball and lockfile. Three installed read-only Tier1 operations: anonymous public session initialization, address search, selected feature details. No browser, LLM healing, registry sharing or personal cookies in runtime. The process creates a separate anonymous visitor session from Visicom's public response; without it this site's search can return misleading empty results. Guest bootstrap is refreshed every15minutes, not once per customer. Only the fixed HTTPS host and GET routes are permitted. Search is bounded by deadlines, response size and durable owner/global quotas6/60perminute. No whole-city download or periodic map polling.

Candidates require the selected settlement/country and compatible street type/name. Other same-name towns are rejected. Same spelling at multiple coordinates does not prevent selection. Exact number formatting may normalize `8/а` to `8а` for search only; `10а/51` is never equated with10. Missing house detail returns the matching street with `precision:street`. User explicitly chooses a result. Source and checkedAt are stored; coordinates identify an approximate feature and never imply a power circuit.

Save uses `{action:save,confirmed:true,address:{mapCandidateToken},name?}`. The server signs the owner, original input and selected feature for10minutes, checks the provider again, allocates private canonical references and calls existing profile creation in one owner-locked transaction. Original street/house strings are preserved. Duplicate addresses reuse identity; maximum10profiles still applies. Map references stay absent from public provider search/resolve. No provider line, queue, provider plan or current power state is fabricated.

Map-only Home exposes approximation, a map link, provider plan unavailable and sensor binding. Existing BE-06 identity/claim/invite/1:1rules apply. Signal reads use the linked sensor/current binding, authenticated afresh. Fresh synchronized on/off is shown only while the confirmed sample and transport remain fresh; the UI expires an open result to unknown. No cache, map proximity, missing heartbeat or street-level match turns into off. Current test ingest/history1006/1007 are preserved. Physical-device validation, Android integration, installed-device QA, commercial map rights and production publication are separate pending work.
