# Каталог зарядок

PostGIS обслуговує viewport із нашої бази. Запит з карти ніколи не звертається до провайдера зарядок. Карта й окремий збирач мають власні прапорці, за замовчуванням вимкнені. GPS і маршрутизація не потрібні.

Перед пілотом переглянути актуальні умови обраних записів за [документацією Open Charge Map](https://github.com/openchargemap/ocm-docs/blob/master/System/DeveloperGuide.md) та [схемою API](https://github.com/openchargemap/ocm-docs/blob/master/Model/schema/ocm-openapi-spec.yaml). Адаптер перевіряє точний ID постачальника та ліцензію кожного запису. Різні постачальники OCM можуть мати різні умови. Для першого пілоту дозволити лише записи Open Charge Map Contributors після підтвердження умов CC BY-SA 4.0, включно з атрибуцією та умовами повторного поширення.

1. Отримати ключ для цього проєкту та зберегти його як `/run/charging/ocm-key` у worker. Прапорці в БД лишити вимкненими під час перевірки конфігурації.
2. На копії БД вручну перевірити малий пілотний прямокутник. Імпортувати лише перевірені записи з атрибуцією; великий корпус спочатку розбивати на обмежені ділянки й перевіряти пропуски.
3. Для відомих станцій увімкнути `collector_enabled` після перевірки дозволів. Worker планує не більше одного точного OCM ID за хвилину, застосовує зміни й підтверджує завдання в одній транзакції. Відсутність запису в одному запиті не позначає станцію офлайн.
4. Публічний viewport і прогноз вмикати окремо. Точну лінію живлення вносити лише за документованим підтвердженням; після зміни координат або адреси перевірку повторити. Графік мережі показує умовне вікно й не підтверджує роботу конектора. Стан конекторів потребує окремого джерела зі свіжими спостереженнями.
