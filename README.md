# Світло · сайт версії 1.3.3

Безкоштовний Android-застосунок для перегляду графіків відключень електроенергії.

## Сайт

[Відкрити сайт](https://sergioyankovenko.github.io/svitlo/). GitHub Pages публікує корінь гілки `main`.

## Завантаження

[APK 1.3.3](downloads/Svitlo-1.3.3.apk) · [SHA-256](downloads/Svitlo-1.3.3.sha256.txt)

Android 8.0+, versionCode 9. Розмір APK — 2 089 152 байти. Файл збігається з перевіреною підписаною збіркою 1.3.3. Попередній APK залишено для історії, але всі кнопки сайту ведуть на нову версію.

## Що оновлено

- Просторіший головний блок та галерея з повними пропорціями знімків: без фіксованого обрізання й розтягування.
- П'ять нових знімків справжнього інтерфейсу 1.3.3: головна, підсумок і погода, повідомлення, опції та віджети. Використано демонстраційні адресу, графік і погоду; приватні дані не публікуються.
- Актуальний опис: кілька адрес, погодинні плитки, 24 години погоди, тижнева історія повідомлень, віджети та нагадування.
- Збільшення знімків із підтримкою клавіатури, FAQ, адаптація до вузьких екранів і збільшеного тексту, нова картка для поширення посилання.

## Локальний перегляд

`python -m http.server 8765 --bind 127.0.0.1`

Відкрийте `http://127.0.0.1:8765/`. Збірка та npm-залежності не потрібні. Стилі — `assets/site.css`, поведінка галереї — `assets/site.js`. Знімки також відкриваються звичайними посиланнями без JavaScript. `assets/social-card.html` — джерело картки посилання; її PNG знято у браузері при 1200×630.

Перевірки: [SITE-CHECKS.md](SITE-CHECKS.md).

Незалежний проєкт, неофіційний застосунок АТ «Черкасиобленерго».

**Обережно:** не додавайте у відкритий репозиторій вихідний архів Android Studio, keystore, ключі підпису чи приватні облікові дані.
