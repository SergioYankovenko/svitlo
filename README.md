# Світло · Android та iPhone

Безкоштовний застосунок для перегляду графіків відключень електроенергії на Android та iPhone. Світла й темна теми, збережені адреси, погода та сповіщення. Віджети доступні на Android.

## Завантаження

[Відкрити сайт](https://sergioyankovenko.github.io/svitlo/) · [Встановити на Android](downloads/Svitlo-1.6.0.apk) · [Встановити на iPhone](https://sergioyankovenko.github.io/svitlo/app/) · [SHA-256 APK](downloads/Svitlo-1.6.0.sha256.txt)

Android 8.0+, versionCode 25. Розмір APK · 2 229 032 байтів. Оновлення встановлюється поверх попередньої версії зі збереженням адрес і віджетів.

На iPhone: відкрити посилання у Safari → «Поширити» → «На Початковий екран» → «Додати». Для сповіщень потрібні iOS 16.4+, відкриття зі встановленої іконки й дозвіл в опціях. Час доставки залежить від системи.

## Що оновлено в Android 1.6.0

Надійніші щоденні повідомлення, обмежені повтори після тимчасових помилок та відсутність дублікатів. Картки зберігають погоджений вигляд; нових перемикачів і блоків дозволу немає. Уніфіковані спливні вікна й виправлені натискання в адресних списках.

Повний перелік і перевірки: [Android 1.6.0](ANDROID-RELEASE-1.6.0.md). PWA/iPhone цим Android-релізом не змінюється.

## Публікація й автоматичне оновлення

GitHub Pages публікує корінь гілки `main`. [update.json](update.json) містить versionCode, URL підписаного APK, дату публікації та SHA-256. Маніфест і APK публікуються одним комітом. Встановлення користувач підтверджує самостійно; системні сповіщення потребують дозволу.

Для 1.3.x потрібне перше ручне оновлення. Попередні APK залишено для історії; кнопки сайту ведуть на 1.6.0. Знімки отримано з підписаного Android 1.5.7, з демонстраційними адресами, погодою та графіками. Віджети показані окремими зображеннями. Підписи зберігають версію джерела; опис і контрольні суми: SCREENSHOTS-1.5.7.md та SCREENSHOTS-1.5.7.json. Інтерактивний перегляд світлої й темної теми, дві інструкції встановлення та картка посилання для обох платформ.

У FAQ коротко описано приватність, зберігання даних, встановлення й роботу графіків. Маскот і правила наступних ілюстрацій: MASCOT-STYLE.md.

## Перевірки

Android 1.6.0, збірка 25: 602 автоматичні тести без помилок і пропусків; lint release — 0 помилок, 119 попереджень. На Android 8/15 пройшли 20 сценаріїв повідомлень у двох темах і зі шрифтом до 200%. Живе приватне отримання й одноразовий системний показ перевірені на Xiaomi 13T та Samsung Galaxy A53. Підписане оновлення з 1.5.9 зберігає адреси; озвучування TalkBack та доставка під Doze/force-stop не перевірялися.

Перевірки сайту: [SITE-CHECKS.md](SITE-CHECKS.md).

## Локальний перегляд

`python -m http.server 8765 --bind 127.0.0.1`

Відкрийте `http://127.0.0.1:8765/`. Збірка та npm-залежності не потрібні. Стилі · `assets/site.css`, поведінка галереї · `assets/site.js`.

Незалежний проєкт, неофіційний застосунок АТ «Черкасиобленерго».
