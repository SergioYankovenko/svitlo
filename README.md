# Світло · Android та iPhone

Безкоштовний застосунок для перегляду графіків відключень електроенергії на Android та iPhone. Світла й темна теми, збережені адреси, погода та сповіщення. Віджети доступні на Android.

## Завантаження

[Відкрити сайт](https://sergioyankovenko.github.io/svitlo/) · [Встановити на Android](downloads/Svitlo-1.5.0.apk) · [Встановити на iPhone](https://sergioyankovenko.github.io/svitlo/app/) · [SHA-256 APK](downloads/Svitlo-1.5.0.sha256.txt)

Android 8.0+, versionCode 13. Розмір APK — 2 138 360 байтів. Оновлення встановлюється поверх попередньої версії зі збереженням адрес і віджетів.

На iPhone: відкрити посилання у Safari → «Поширити» → «На Початковий екран» → «Додати». Для сповіщень потрібні iOS 16.4+, відкриття зі встановленої іконки й дозвіл в опціях. Час доставки залежить від системи.

## Що оновлено в Android 1.5.0

Точне визначення черги без вгадування, коректний невідомий стан і пояснення збоїв, нові вигляди плиток та лампочки, плавні свайпи між днями, компактніша шапка й налаштування, спільний час нагадувань та точні розрахунки 23/25-годинної доби. Додано мінімальний добовий облік активних установок без адрес і рахунків у сигналі.

Повний перелік і межі перевірок: [Android 1.5.0](ANDROID-RELEASE-1.5.0.md). Поточну PWA/iPhone збережено без змін.

## Публікація й автоматичне оновлення

GitHub Pages публікує корінь гілки `main`. [update.json](update.json) містить versionCode, URL підписаного APK, дату публікації та SHA-256. Маніфест і APK публікуються одним комітом. Встановлення користувач підтверджує самостійно; системні сповіщення потребують дозволу.

Для 1.3.x потрібне перше ручне оновлення. Попередні APK залишено для історії; кнопки сайту ведуть на 1.5.0. На сайті — нові знімки справжнього Android 1.4.2 та поточного клієнта для iPhone у мобільному браузері, із демонстраційними адресою, погодою та графіком. Інтерактивний перегляд світлої й темної теми, дві інструкції встановлення та картка посилання для обох платформ.

## Перевірки

Android 1.5.0: 482 автоматичні тести; lint — 0 errors, 88 warnings; 148 сценаріїв на емуляторах Android 8/15, обидві теми, обидва вигляди й набори значків, шрифт 100/150/200%. Оновлення поверх 1.4.2 зберегло адреси й прив’язки віджетів на обох емуляторах. Користувач перевірив свій телефон. Повне приймання TalkBack не підтверджене — автоматизований перехід між плитками не пройшов.

Перевірки сайту: [SITE-CHECKS.md](SITE-CHECKS.md).

## Локальний перегляд

`python -m http.server 8765 --bind 127.0.0.1`

Відкрийте `http://127.0.0.1:8765/`. Збірка та npm-залежності не потрібні. Стилі — `assets/site.css`, поведінка галереї — `assets/site.js`.

Незалежний проєкт, неофіційний застосунок АТ «Черкасиобленерго».

**Обережно:** не додавайте у відкритий репозиторій вихідний архів Android Studio, keystore, ключі підпису чи приватні облікові дані.
