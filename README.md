# Світло · версія 1.4.2

Безкоштовний Android-застосунок для перегляду графіків відключень електроенергії.

## Завантаження

[Відкрити сайт](https://sergioyankovenko.github.io/svitlo/) · [APK 1.4.2](downloads/Svitlo-1.4.2.apk) · [SHA-256](downloads/Svitlo-1.4.2.sha256.txt)

Android 8.0+, versionCode 12. Розмір APK — 2 113 784 байти. Оновлення встановлюється поверх попередньої версії зі збереженням адрес і віджетів.

## Що оновлено

- Повторна перевірка джерела, зміна адреси та повторне відкриття застосунку більше не поновлюють актуальність застарілої аварійної команди. Обласне попередження й підтверджені аварії за адресою обробляються окремо.
- Світла й темна теми мають плоскі кнопки та діалоги без тіней.
- Перевірка нової версії виконується автоматично раз на добу, без окремої картки ручної перевірки. Android може відкладати фонову перевірку.
- В опціях додано кнопку «Подякувати за додаток» для добровільного донату. Застосунок залишається безкоштовним.

Для обласної команди без вказаного завершення поточний банер потребує свіжої перевірки й показується протягом двох годин від публікації або початку дії. Явно зазначений інтервал дії має пріоритет. Приховування старого банера не означає фізичного відновлення світла чи гарантії 24 годин без відключень.

## Публікація й автоматичне оновлення

GitHub Pages публікує корінь гілки `main`. [update.json](update.json) містить versionCode, URL підписаного APK, дату публікації та SHA-256. Маніфест і APK публікуються одним комітом. Встановлення користувач підтверджує самостійно; системні сповіщення потребують дозволу.

Для 1.3.x потрібне перше ручне оновлення. Попередні APK залишено для історії; кнопки сайту ведуть на 1.4.2. Знімки інтерфейсу на сайті залишаються демонстрацією версії 1.3.3 й підписані відповідно.

## Перевірки

Android-реліз: 458 тестів, 44 набори, без помилок і пропусків. Lint: 0 помилок, 68 попереджень. Підписаний APK перевірено на емуляторах Android 8 та 15, включно з оновленням зі збереженням даних, обома темами та шрифтом 200%. Фізичні телефони в цьому циклі не тестувалися.

Перевірки сайту: [SITE-CHECKS.md](SITE-CHECKS.md).

## Локальний перегляд

`python -m http.server 8765 --bind 127.0.0.1`

Відкрийте `http://127.0.0.1:8765/`. Збірка та npm-залежності не потрібні. Стилі — `assets/site.css`, поведінка галереї — `assets/site.js`.

Незалежний проєкт, неофіційний застосунок АТ «Черкасиобленерго».

**Обережно:** не додавайте у відкритий репозиторій вихідний архів Android Studio, keystore, ключі підпису чи приватні облікові дані.
