# Світло · Android та iPhone

Безкоштовний застосунок для перегляду графіків відключень електроенергії на Android та iPhone. Світла й темна теми, збережені адреси, погода та сповіщення. Віджети доступні на Android.

## Завантаження

[Відкрити сайт](https://sergioyankovenko.github.io/svitlo/) · [Встановити на Android](downloads/Svitlo-1.5.7.apk) · [Встановити на iPhone](https://sergioyankovenko.github.io/svitlo/app/) · [SHA-256 APK](downloads/Svitlo-1.5.7.sha256.txt)

Android 8.0+, versionCode 20. Розмір APK — 2 200 360 байтів. Оновлення встановлюється поверх попередньої версії зі збереженням адрес і віджетів.

На iPhone: відкрити посилання у Safari → «Поширити» → «На Початковий екран» → «Додати». Для сповіщень потрібні iOS 16.4+, відкриття зі встановленої іконки й дозвіл в опціях. Час доставки залежить від системи.

## Що оновлено в Android 1.5.7

Віджети з окремими графіками адрес і сторінками по чотири, оновлення погоди й таймера без зайвої перебудови головної, надійніше додавання адрес та зіставлення джерел, поширення графіка, компактніші повідомлення й узгоджені позначення.

Повний перелік і перевірки: [Android 1.5.7](ANDROID-RELEASE-1.5.7.md). PWA/iPhone цим Android-релізом не змінюється.

## Публікація й автоматичне оновлення

GitHub Pages публікує корінь гілки `main`. [update.json](update.json) містить versionCode, URL підписаного APK, дату публікації та SHA-256. Маніфест і APK публікуються одним комітом. Встановлення користувач підтверджує самостійно; системні сповіщення потребують дозволу.

Для 1.3.x потрібне перше ручне оновлення. Попередні APK залишено для історії; кнопки сайту ведуть на 1.5.7. Скриншоти залишено без змін: приклади Android 1.4.2 та версії для iPhone у мобільному браузері, із демонстраційними адресою, погодою та графіком. Підписи не видають ці знімки за поточний Android 1.5.7. Інтерактивний перегляд світлої й темної теми, дві інструкції встановлення та картка посилання для обох платформ.

У FAQ описано зберігання даних, серверне визначення черги й мінімальний добовий сигнал Android для приблизного обліку активних установок. У сигналі немає адреси чи рахунку.

## Перевірки

Android 1.5.7: 549 автоматичних тестів без помилок; lint release без помилок; 12 цільових нативних QA-сценаріїв на Android 8/15, дві теми та шрифт 100/150/200%. Підписаний реліз оновив 1.5.0 на обох емуляторах зі збереженням адрес і прив'язок віджетів. Користувач перевірив тестову збірку на телефоні. Озвучування TalkBack окремо не перевірялося.

Перевірки сайту: [SITE-CHECKS.md](SITE-CHECKS.md).

## Локальний перегляд

`python -m http.server 8765 --bind 127.0.0.1`

Відкрийте `http://127.0.0.1:8765/`. Збірка та npm-залежності не потрібні. Стилі — `assets/site.css`, поведінка галереї — `assets/site.js`.

Незалежний проєкт, неофіційний застосунок АТ «Черкасиобленерго».

**Обережно:** не додавайте у відкритий репозиторій вихідний архів Android Studio, keystore, ключі підпису чи приватні облікові дані.
