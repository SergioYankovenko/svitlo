# Світло · Android та iPhone

Безкоштовний застосунок для перегляду графіків відключень електроенергії на Android та iPhone. Світла й темна теми, збережені адреси, погода та сповіщення. Віджети доступні на Android.

## Завантаження

[Відкрити сайт](https://sergioyankovenko.github.io/svitlo/) · [Встановити на Android](downloads/Svitlo-1.5.8.apk) · [Встановити на iPhone](https://sergioyankovenko.github.io/svitlo/app/) · [SHA-256 APK](downloads/Svitlo-1.5.8.sha256.txt)

Android 8.0+, versionCode 22. Розмір APK — 2 200 360 байтів. Оновлення встановлюється поверх попередньої версії зі збереженням адрес і віджетів.

На iPhone: відкрити посилання у Safari → «Поширити» → «На Початковий екран» → «Додати». Для сповіщень потрібні iOS 16.4+, відкриття зі встановленої іконки й дозвіл в опціях. Час доставки залежить від системи.

## Що оновлено в Android 1.5.8

У легенді великого віджета — один кольоровий зразок відключення для видимої сторінки: поточна подія або найближча майбутня. Самі графіки зберігають усі свої кольори. Збережено виправлення повторного додавання компактного віджета. Нова версія та назва APK допомагають відрізнити актуальну збірку від раніше завантаженої.

Повний перелік і перевірки: [Android 1.5.8](ANDROID-RELEASE-1.5.8.md). PWA/iPhone цим Android-релізом не змінюється.

## Публікація й автоматичне оновлення

GitHub Pages публікує корінь гілки `main`. [update.json](update.json) містить versionCode, URL підписаного APK, дату публікації та SHA-256. Маніфест і APK публікуються одним комітом. Встановлення користувач підтверджує самостійно; системні сповіщення потребують дозволу.

Для 1.3.x потрібне перше ручне оновлення. Попередні APK залишено для історії; кнопки сайту ведуть на 1.5.8. Скриншоти залишено без змін: приклади Android 1.4.2 та версії для iPhone у мобільному браузері, із демонстраційними адресою, погодою та графіком. Підписи не видають ці знімки за поточний Android 1.5.8. Інтерактивний перегляд світлої й темної теми, дві інструкції встановлення та картка посилання для обох платформ.

У FAQ описано зберігання даних, серверне визначення черги й мінімальний добовий сигнал Android для приблизного обліку активних установок. У сигналі немає адреси чи рахунку.

## Перевірки

Android 1.5.8, збірка 22: 565 автоматичних тестів без помилок і пропусків; lint release — 0 помилок, 120 попереджень. На Android 8/15 перевірені системне додавання обох віджетів, скасування, повторний запит і видалення; легенда на трьох розмірах, включно зі шрифтом 200%. Підписане оновлення з 1.5.7 (збірка 21) зберегло адреси й віджети. Озвучування TalkBack та launcher фізичного телефона окремо не перевірялися.

Перевірки сайту: [SITE-CHECKS.md](SITE-CHECKS.md).

## Локальний перегляд

`python -m http.server 8765 --bind 127.0.0.1`

Відкрийте `http://127.0.0.1:8765/`. Збірка та npm-залежності не потрібні. Стилі — `assets/site.css`, поведінка галереї — `assets/site.js`.

Незалежний проєкт, неофіційний застосунок АТ «Черкасиобленерго».

**Обережно:** не додавайте у відкритий репозиторій вихідний архів Android Studio, keystore, ключі підпису чи приватні облікові дані.
