# PWA 1.1.9 — позапланові відключення

Позапланові адресні події більше не підписуються як планові роботи. Сервер розпізнає «позаплан» у DISCONN_TYPE й передає окрему boolean-ознаку всередині planned. Три категорії та три запити до провайдера збережені; старі клієнти сумісні. Передбачено уточнення старого кешу без видалення адрес і без вигадування втрачених історичних даних.

Додано назву «Позапланове відключення» до шапки, повної легенди й доступних описів; коротка легенда використовує відповідний типу колір. Фон #78579F / #7D5DA6, темні значки #14251E, світлі цифри #F0F3E8. Підтримано обидві теми, блискавки/лампочки, обидва вигляди часу, змішані половинки й плитку зміни часу. Точні інтервали, підсумки, таймер, нагадування та пріоритет категорій збережені.

255/255 автоматичних тестів; 72 браузерні варіанти тексту/ширини/теми/вигляду, 24 окремі browser zoom перевірки, піксельна перевірка 8 знімків, справжній локальний SW/offline reload. Повний синтетичний шлях provider → Source → HTTP API → кеш → UI, старий кеш і чинні Postgres JSON RPC перевірені. Фізичні телефони та реальна доставка push не входили до цього прогону.

Серверні артефакти API/jobs: незмінний коміт `baa41b8e432e1067b35639c74bdcc41d9a84e36f`, каталог `supabase/releases/pwa-1.1.9`. Нова SQL-міграція не потрібна. Android 1.5.7, APK, лендинг і update.json з попереднього коміту збережені. Ручні jobs/масові push не запускати для міграції; дані уточнюються штатними sync і scheduler.
