# Світло PWA 1.1.0 — локальний результат

24.10.2026. База: 08223fa / 1.0.1. Реалізацію погоджено користувачем після аналізу. Після окремого доручення застосовано production-міграцію, розгорнуто три Edge Functions, активовано довідник і розклад; клієнт публікується через GitHub Pages із main. Журнал публікації ведеться окремо в work/diagnostics-pwa-review-20261024/DEPLOYMENT.md. Адміністративних розсилок і ручного виклику svitlo-jobs не виконували. Android, спільний макет і ПРАВКИ.md не редагувалися. Попередні зміни PWA-TESTS.md збережено.

## Перевірено автоматично

`npm test`: **70 пройшло, 0 помилок**. Серед них сирі/округлені інтервали, обидві половини години, категорії, невідома черга, старі аварійні команди, кеш/sourceAt, адресна ізоляція, відмови джерела, DST 23/25, SW shell/offline/API bypass та існуючі push-контракти без живої розсилки. Імпорт 12 документів, повторний запуск через 14 днів без повторного розбору й розбір лише одного зміненого PDF також перевірені.

PGlite виконав початкову й нову SQL-міграції: атомарне перемикання реєстру, rollback помилкового кандидата зі збереженням активної версії, заборона прямого доступу authenticated, next_check/backoff.

`npm run build`: клієнт у dist/app і три Edge bundles. Service worker включає tiles.js та отримує новий хеш shell. `git diff --check` без помилок пробілів.

Фінальний shell: `svitlo-pwa-4f4412919107`. Клієнтський пакет: output/Svitlo-PWA-1.1.0.zip, SHA-256 `2019afea936ce0aeca9dba3bbdd442cea7276b597327c5c503b8d4ccc568ee5e`. Серверні міграції та функції зберігаються окремо в репозиторії.

## Перевірено в Chrome локально

Ізольований HTTP-сервер із синтетичними профілями; production не використовувався.

- Обидві теми × обидва вигляди × 320/360/414 × 100/150/200% кореневого розміру тексту: **36 комбінацій**, горизонтального переповнення немає. Для нового вигляду додатково перевірено межі кожного рядка часу. Стовпці переходять з 4 до 3 або 2, на широкому екрані зберігаються 6.
- Це контрольоване збільшення тексту CSS rem, а не зміна налаштування шрифту реального телефона.
- Старий режим при першому відкритті; новий режим і тема зберігаються після перезавантаження.
- Невідома черга не має підтверджених добових підсумків; відомі адресні події залишаються видимими.
- Історична кнопка відкрила 23.10; поточного аварійного банера від неї немає.
- Діалог точних інтервалів відповідає темі, закривається Escape, фокус повертається на плитку.
- Розрахований контраст тексту плиток із базовими тлами: від 5.77:1 (аварійне) до 13.31:1 (темне звичайне). Це перевірка цих пар кольорів, не повний аудит доступності застосунку.
- Після зупинки локального сервера SW відкрив збережений shell і 24 плитки; клієнт показав нейтральну помилку оновлення, невідома черга залишилась невідомою. Це тест недоступності сервера, не фізичного режиму польоту.
- При зміні збірки виявлено очікуваний цикл SW: стара відкрита вкладка зберігає старий shell; новий активується після закриття контрольованих вкладок. Фінальний вигляд оглянуто також на чистому локальному origin.

Матеріали: work/diagnostics-pwa-review-20261024 у спільній робочій папці: tests-final.txt, ui-matrix.json, ui-legacy-matrix.json, ui-browser-zoom.json, local-registry.json, pwa-dark-final.png, pwa-light-final.png.

## Межі перевірки

- Реальний browser zoom 150/200% **не підтверджено**: комбінації клавіш через браузерний інструмент не дали надійно спостережуваної зміни. Записи ui-browser-zoom.json є журналом спроб, не успішним тестом zoom. Контрольоване збільшення тексту вище не замінює цю перевірку.
- TalkBack/VoiceOver, системне збільшення тексту телефона, iPhone та нова Android-збірка не перевірялися. Перевірено DOM-описи й клавіатуру в Chrome.
- Hosted Deno/Edge runtime після дозволу перевірено успішним живим імпортом усіх 12 PDF; production-міграцію й розклад застосовано. Живі нагадування вручну не викликалися, їх доставку цим патчем повторно не перевіряли.
- Реєстр містить **58 підтриманих однозначних правил**, а не повний адресний довідник області. Непідтримані часткові адресні формулювання залишаються невідомими. Новий формат офіційних PDF може вимагати адаптації імпортера; невдалий імпорт зберігає попередню версію.

Контракт Android-доступу: QUEUE-REGISTRY-API.md. Окреме доручення на публікацію та production-зміни отримано 24.10.2026; сервер уже перевірено живими запитами. Часткове покриття реєстру та неперевірені мобільні сценарії не змінюються після розгортання.
