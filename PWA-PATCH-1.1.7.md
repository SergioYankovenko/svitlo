# PWA 1.1.7

Патч стабільності запуску та налаштувань сповіщень.

- Під час запуску не показується хибний екран повторного додавання адрес. Тимчасова помилка Auth не створює нового анонімного користувача; оновлення токена того самого користувача зберігає кеш. Підтверджена втрата сеансу веде на звичайний початковий екран.
- Запізнілі відповіді не повертають видалені дані. Помилки storage мають fallback у пам'ять; пошкоджений/чужий кеш відкидається. Зміни адрес і налаштувань зберігають решту кешу та початковий вік даних.
- Запуск графіка незалежний від SW/push. Оболонка використовує узгоджений кеш, перевіряє SHA-256 файлів і захищає перший перехід зі старого SW від змішування HTML та JS. Збережено активацію оновлення після закриття всіх вікон.
- Збережена тема застосовується рано; вибір адреси з посилання, календарні дати, фокус, введення в діалогах та повторна спроба завантаження SDK обробляються стійкіше.
- Біля заголовка «Сповіщення» — дзвіночок 28×28 з доступною підказкою замість окремого рядка дозволу. Іконка та кнопка відображають фактичний стан, включно з помилками операцій.
- У списку «Нагадувати за» прибрано галочку біля вибраного часу. Рамка, клавіатура, доступний стан та збереження вибору залишилися.

Перевірки: 245 автоматичних тестів; контрольовані локальні браузерні сценарії запуску/CRUD/Auth, обидві теми, 320/360/414, текст 100/150/200%, окремо справжній browser zoom, upgrade/offline, модельні 23/25-годинні доби. Фізичні телефони, читачі екрана й реальна доставка push окремо не перевірялись.

App-shell текстові файли нормалізуються в LF перед хешуванням; Git attributes зберігають ті самі байти при публікації. Серверні функції, Supabase-схема/дані, Android, APK, лендинг та update.json не входять до релізу.
